# v0.2 검증 기록

기록일: 2026-11-02. 독립된 `dongne-lens-quest` 소스에서 검증했습니다.

## 자동 검사

| 검사 | 결과 |
| --- | --- |
| Python 계산·자료 파싱·HTTP·신규 실험 | **66개 통과** (기본 분석 17, 실험 24, 자료 조회 12, HTTP 13) |

명령은 README에 있습니다. 구성만 달라진 예제의 전체 +100%/같은 구성 0%, 고정 가중치, 표본 부족 null, 기간·면적·동·지역 경계, 거래 해제, 부적절한 입력, 블라인드 후보 재현성을 검사했습니다. HTTP 검사는 키 없는 공식 조회 오류, 가상 조회→분석/실험, 예제 표시, 정적 파일과 비공개 소스 분리를 포함합니다.

## 브라우저 검사

관리형 미리보기에서 Chrome으로 확인했습니다.

- 3D 아파트 마을 표시와 움직임 정지 버튼.
- 가격 착시 가상 예제의 전체 +100%와 같은 구성 0% 공개.
- 블라인드 B 후보 선택 → 이름 공개 → 다시 선택 → C 후보로 변경 및 설명.
- 3개월·60~85㎡·청담동으로 좁히면 매매 3건, 적합도 보류, 착시 매칭 자료 부족, 블라인드 후보 부족 표시.
- 부산 검색 시 이전 거래·실험·점수를 지우고 목적지 재선택 표시, 저장/공유 비활성화.
- 공식 API 키가 없을 때 공식 모드 선택 비활성화.
- 390px·768px iframe 안의 반응형 첫 화면을 검사했습니다. 스크롤바 제외 문서 폭 375px·753px에서 가로 넘침이 없었습니다. 실제 휴대전화 검증과는 다릅니다.

검토 중 예제 응답이 이후 지역 탭 전환을 덮는 요청 순서 문제, 이전 목적지 표시 잔류, 작은 설명 글자의 대비를 수정했습니다. 3D의 동작 줄이기 설정·화면 밖 정지는 소스 검토했으며 기기 설정 변경으로 재현하지는 않았습니다.

## 별도 확인이 필요한 범위

- 실제 발급키를 이용한 국토부 응답과 Replit 게시 환경 외부 API 연결.
- 실제 모바일 기기와 다양한 브라우저 조합.
- 대규모 동시접속·장기 운영 부하. 현재는 개인 실험과 작은 프로토타입용 서버입니다.

GitHub 생성·업로드는 코드 검증과 별개입니다. 원격 파일·커밋이 확인된 경우에만 완료로 보고합니다.
