# 60초 시연 — 숫자와 이름 사이에서 내 집 찾기

시연 전 가상 예시 모드·최근 6개월·전체 면적을 선택합니다. 이 시연의 가격은 실제 시장자료가 아닙니다.

| 시간 | 조작 | 말할 내용 |
| --- | --- | --- |
| 0–10초 | 3D 마을을 보여주고 관심 구를 검색 | “내가 살 집을 찾아가는 작은 탐험입니다. 숫자와 동네 이름을 다르게 읽어보는 두 실험을 만들었습니다.” |
| 10–30초 | 가격 착시 탐정의 연습 예제 열기 | “이 가상 예제에서는 작은집 5억, 넓은집 10억이 그대로입니다. 넓은집 거래 비중만 커져 전체 중앙값은 100% 올랐고, 같은 구성 비교는 0%입니다.” |
| 30–50초 | 지역 결과로 복귀하고 블라인드 후보 선택 → 이름 공개 → 유지/변경 | “가격·면적만 보고 고른 집입니다. 이름을 알아도 같은 선택을 할까요? 정답을 주기보다 내가 중요하게 보는 조건을 발견하게 합니다.” |
| 50–60초 | 거래 요약·내 자금 계획으로 이동 | “출처와 표본 수를 함께 보여주고, 내 예산과 금리로 부담을 확인합니다. 실제 자료는 국토부 API를 연결하면 조회할 수 있습니다.” |

## 시연에서 지킬 표현

- 실제 지역 데이터와 연습 예제를 구분합니다. 연습 예제의 100%는 선택 지역의 가격 변동이 아닙니다.
- 같은 구성 비교도 층·향·상태가 다른 거래를 포함합니다. 공식 가격지수나 상승 원인 판정이라고 설명하지 않습니다.
- 블라인드 카드는 과거 표본의 집계이며 현재 매물이 아닙니다. 이름 공개 후의 선택은 성향 진단이나 투자 등급으로 점수화하지 않습니다.
- 차별점은 **보기 좋은 탐험 화면 + 해석을 바꾸는 체험 + 근거 공개**입니다. 다른 서비스에 전혀 없는 기능이나 수상을 보장한다고 주장하지 않습니다.

## 표본이 부족할 때

기간을 12개월로 넓히거나 동·면적 조건을 해제합니다. 그래도 비교 가능한 그룹이 없으면 부족 상태를 그대로 보여주고 착시 연습 예제를 사용합니다. 빈 결과에 숫자를 채워 시연하지 않습니다.
